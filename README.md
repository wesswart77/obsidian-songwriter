# Songwriter

A songwriter's notebook for Obsidian: lyrics, chords, song structure, themes, influences, and recording notes.

## Features

- **New Song** — title, status, key, tempo, time signature, genre, themes, influences
- **Song structure** — frontmatter + Lyrics (Verse 1/Chorus/Verse 2/Bridge/Outro), Chords, Notes, Recording Ideas
- **Lyric Snippets** — capture hooks, verse ideas, chorus lines, and bridges in a Snippets folder
- **Find Rhymes** — quick-launch helper that reminds you to check a rhyme dictionary
- **Songs Sidebar** — list songs grouped by status with title, key, and status badge

## Settings

- **Songs folder** — where song notes are stored (default: `Songs`)
- **Snippets folder** — where lyric snippet notes are stored (default: `Songs/Snippets`)
